# Jev examples

A collection of toy projects for testing Jev's typed judgments, scoring, and
classification in small applications and benchmarks. These are experiments, not
production-ready systems.

> [!NOTE]
> This code was generated with AI assistance and has been curated by a human.
> Human curation does not guarantee correctness; review and test it before relying on it.

## Folders

| Folder | Summary |
| --- | --- |
| [`proof_practice/`](proof_practice/README.md) | A proof study app with Jev rubric scoring, custom questions, answer comparisons, and evaluations. Feedback is not formal proof verification. |
| [`abcd_benchmark/`](abcd_benchmark/README.md) | Tests Jev on customer-service conversations: action prediction, workflow handling, and intent routing. |
| [`bitext_benchmark/`](bitext_benchmark/README.md) | Tests Jev on intent classification for individual customer-service messages. |
| [`sentiment_benchmark/`](sentiment_benchmark/README.md) | Compares Jev Choice and Noul sentiment predictions on held-out UCI Amazon, IMDb, and Yelp sentences. |

See each project's README for setup and usage. Live Jev calls can incur charges;
keep API keys and real `.env` files private.
